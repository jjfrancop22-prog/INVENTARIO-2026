# V1.0.8 — Clasificación y base de cálculo de recursos
- Se sugiere automáticamente clasificación para estándares, MRC, reactivos, equipos, calibraciones y otros conceptos; usuario puede cambiarla.
- Base editable: pendiente, por muestra, por lote, por período.
- En período, frecuencia en meses configurable: costo anual equivalente = costo período × 12 / meses.
- Costos históricos permanecen sin sumar hasta clasificación manual.
- Alerta de doble contabilización si calibración, mantenimiento, PT o compra de equipo se intenta cargar directamente; usar Costos compartidos.
- No se modifican las cantidades de los 128 parámetros ni los registros existentes.
- Para un MRC o estándar el criterio debe justificarse con consumo o frecuencia real, no se impone uno universal.
