# V1.0.10 — Corrección de entrada numérica

- Los campos con valor cero aparecen vacíos (marcador visual «0») para evitar entradas como 045.
- Al enfocar un campo numérico se selecciona su valor completo, para reemplazar fácilmente 12 por 24.
- Se conservan los cálculos y datos de la V1.0.9, sin modificar las claves de almacenamiento local.
- Continúa siendo una aplicación React/Vite para Terminal.
